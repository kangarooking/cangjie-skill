# Cangjie Skill 联系入口设计

## 目标

在不改变现有 Pixar 式圆润视觉体系的前提下，为官网主导航增加“联系我们”和“交流群”两个入口。用户点击后可直接看到可扫码的微信二维码；个人联系用于项目反馈、内容合作与生态共建，交流群用于 Skill 用法、案例和共建进展交流。

## 视觉与交互

- 采用参考图中的下拉二维码卡片结构：白色圆角卡片、深色描边、偏移彩色阴影、二维码主体与双语小标题。
- “联系我们”使用仓库现有 `assets/wechat-personal-qr.jpg`，保留完整个人信息与二维码画面。
- “交流群”使用仓库现有 `assets/wecom-cangjie-group-qr.png`，保持二维码原始比例，不重新生成或裁切。
- 使用原生 `details/summary` 提供鼠标、触屏与键盘交互；同一时间只展开一个卡片，点击外部或按 Escape 关闭。
- 页脚增加对应按钮，点击后打开同一导航卡片，不复制二维码内容。

## 响应式与验收

- 桌面端卡片锚定在导航项下方；移动端卡片改为视口内固定宽度，并限制最大高度。
- 极窄屏隐藏“使用教程”和“提交 Skill”两个次要顶部链接，相关入口仍保留在页脚。
- 验收包含 Astro 类型检查、测试、生产构建、桌面与移动端视觉检查，以及两个二维码菜单的打开、互斥、外部点击和 Escape 关闭行为。
